# Oscar Delgado — 2026-09-15

## Sprint Week 5 – Blocker Report (2026‑09‑15)

**Blocker 1 – Inconsistent CI Pipeline**
- *What*: The continuous integration pipeline experiences intermittent failures due to outdated Docker base images.
- *Who is affected*: All development squads pulling the `main` branch for feature integration.
- *Proposed fix*: Institute a weekly image‑refresh task and add a pipeline health‑check stage before merge.

**Blocker 2 – Backlog Grooming Lag**
- *What*: The backlog grooming ceremony is regularly postponed, leaving user stories without clear acceptance criteria.
- *Who is affected*: Product owners, developers, and QA teams.
- *Proposed fix*: Formalise a recurring 30‑minute slot on Wednesdays with a strict agenda and a “definition‑of‑ready” checklist.

**Blocker 3 – Test Data Refresh Delays**
- *What*: The test environment data refresh script fails on the first of each month, causing stale data for regression runs.
- *Who is affected*: QA and automated test pipelines.
- *Proposed fix*: Move the refresh to a nightly cron job with alerting on failure, and add a rollback step.

**Blocker 4 – Documentation Sync Gap**
- *What*: Architecture diagrams are updated in Confluence but not reflected in the internal wiki used by new hires.
- *Who is affected*: On‑boarding engineers and cross‑functional collaborators.
- *Proposed fix*: Adopt a single‑source‑of‑truth approach using a synced markdown repo that publishes to both platforms.

**Overall Recommendation**
- Prioritise process‑level improvements before tackling feature work in the next sprint to reduce cycle‑time variance.
